## 3. 任务一：最终主张带上对应原文短引句

### 3.1 扩展现有 Claim，而非增加生成阶段

在 [schemas.py](D:/course/paper-research-assistant/paper_assistant/schemas.py:52) 的 Claim 中增加普通的 `evidence_quotes` 字段，元素只包含 `chunk_id` 和 `quote`。沿用现有 `claim`、`basis`、`citation_ids`，顶层仍为 AnswerAction／AnswerDraft。

结构示意如下，示意文字不进入运行提示的论文参考答案：

```json
{
  "evidence_quotes": [{"chunk_id": "当前可见子块编号", "quote": "该子块中支持本项表述的连续原文"}],
  "claim": "回答原问题某一要点的事实或必要分析",
  "basis": "paper_evidence",
  "citation_ids": ["当前可见子块编号"]
}
```

新生成约定：

- `paper_evidence`：选取支持本条关键事实、范围和限定条件的短引句，再写主张。一个主张需要跨块依据时可列多句，不拼接成伪造的连续原句。
- `analysis`：引句对应论文提供的前提，推论在 claim 中明确表达；原文前提与模型推论分开。推论中使用的方法事实同样需要对应定义原文。
- `model_knowledge`，以及不依赖论文事实的分析：`evidence_quotes` 为空，不为凑格式附上无关引句。

引句保留原文语言、技术名称及必要限定，来自本次 `evidence_sections` 中实际可见的 `shown_text`，其 `chunk_id` 使用该主张原有的 `citation_ids`。只选解释本项内容所需的短句，不整块复制，不另抄论文身份、页码和坐标。

这项结构在原有最终生成中一次返回，没有“先生成整答，再审核改写”的新请求。历史记录缺少该字段时按空列表读取，不迁移旧数据；旧记录不因此变为错误。新字段按现有结构模型解析，不增加引句匹配器、语义判定器或新的修复循环。

### 3.2 主张按问题要点组织

在 [agent_prompt.py](D:/course/paper-research-assistant/paper_assistant/agent_prompt.py) 的当前自主回答协议中，将组织顺序改为：根据原问题确定需要回答的事实、关系和必要影响 → 从已读正文选取对应原句 → 表述该项主张 → 在同一次生成中给出被请求的 direct_answer。

不新建题型分类器、问题提纲模型或取证工具。信息需求继续使用原问题和已有 `missing_information`；claims 的顺序覆盖所问要点，不强制固定数量，也不按检索到的章节逐节介绍。

以 s3 为例，答案需要覆盖局限、东西方搭配差异及相关影响。若作者已经给出影响推测，就保留其推测语气并解释其与问题的关系。只有需要某阶段机制才能完成所问解释时，才使用现有工具取得该阶段定义。已有讨论原文不能替代算法定义；也不要求每次回答局限都读完整套方法。

## 4. 任务二：让正文依据限定解释范围与术语

### 4.1 保持定位信息与正文依据的职责

保留 2.10 已实现的单份 `evidence_sections`、论文／原节名边界和阅读目录。当前自主输入已经剔除摘要正文，不把“删除摘要”重新列为本批新增功能。

目录、标题、查询建议及工具历史继续帮助模型决定下一步。新引句只能选自当前可见正文；不能从目录、检索意图、旧回答或模型记忆中拼出论文原句。原有工具历史按 API 协议保留，不为“净化上下文”删除必要的调用与结果。

最终声明一个阶段的输入、模型或作用时，所选原句应直接覆盖该阶段的定义及其适用范围；不要用另一个阶段的结果段或泛泛讨论段支撑。证据已经覆盖问题时可以直接回答，无需固定追加 `read_context`。

### 4.2 直接答案保留原定义

direct_answer 继续与 claims 在同一次响应生成，只压缩表达，不扩大结论或替换技术类别。保留阶段名称、条件和不确定性；原文没有给出的同义标签不为简短而自行加入。

s6 的评价重点是原文所述食材向量可同时包含多个 1，以及 word2vec 的阶段归属。“二值食材指示向量”足以准确表述；不能再添加使其变为单一激活类别的标签。该例用于复测评价，不写入运行时的特定论文答案模板。

整理现有共享作答约定，删除与新引句字段冲突的“不得复制任何证据原文”等绝对表述；仍限制整段重复。固定 RAG 保留原生成入口，可读取扩展后的共同答案结构，本批先在页面自主 Agent 启用短引句生成约定。
