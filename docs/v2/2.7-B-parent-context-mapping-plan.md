## 3. 实施任务

### B1. 先接通新版本的来源与运行入口

来源 registry 按已有解析版本格式选择读取方式。结构化版本使用 A 的已存储子块、来源范围、章节与内容类型，不要求它提供虚构的 filtered 文件、segment 或原始 PDF 行号。复用已经存在的记录读取与来源一致性职责，不另读一遍全文做审核。

摘要限定、正文限定仍在当前来源资格接口内处理：依据实际保存的章节及来源范围判断，不能将图注、前置信息或混合范围当作整段摘要。不能仅为通过旧接口伪造 `human_review_status=confirmed` 等旧人工状态。范围不明确时保留现有未知语义；旧版本仍读取原有来源格式。

在 `d9_runtime.py`／`agent_runtime.py` 等实际公共入口接通新格式，使 registry 不会在准备问题前就拒绝新版本。读取父子内容使用本次已打开的 store，或随现有版本数据加载，不新建跨会话全局缓存或资源管理层。

### B2. 命中子块后，按父关系展开实际子证据

保留现有检索和重排结果作为锚点；每个命中按 `parent_id` 查询父记录及其 `child_ids`，再按真实内容顺序取回子块。同一父内容只组织一次，同一子块只展示一次，原检索快照与排名记录不改写。

父内容只是组织阅读的容器。模型看到的证据仍由实际保存的子块构成，每条带原子块 ID、真实页码和完整原文；跨页父内容展示多条对应页内子证据。不能给某个子块 ID 填上整段父文本，也不能将整个父内容另造一个可引用 ID。

新补入的子块沿现有 `reading_origins` 记录锚点及父关系，注明是本地父上下文读取，不记成新检索、自主决策或额外模型调用。相似度分数只表示原锚点的来源，不给未检索的子块编造独立相关性分数。

保留当前跨查询的证据次序：先保障按既有规则选出的锚点，再在预算内补父内容关联子块；同一父内容被多次命中时合并其读取。预算不足时保留完整子块并沿现有省略记录说明，不裁剪 `shown_text` 后仍声称展示了整个原子块。

### B3. 统一预算与上下文记录

结构化上下文以总计 **8192 token** 为初始证据预算，复用 A 已下载的本地 tokenizer 作统一计量；它是选择预算口径，不冒充生成服务返回的真实 usage。计量包含模型实际收到的证据文本及必要标题／标识，生成模型、输出 4096 token、五步 Agent 和一次格式修复策略不变。整体请求沿用已配置模型的实际输入窗口，不额外发请求估算 token。

结构化路径不能仍先受 8000 字符或展开后最多 8 条的旧限制。将预算贯通 `select_context`、跨查询合并、来源筛选、历史引用恢复、父内容读取、`build_messages` 及其现有记录读取位置；不得仅放大入口参数，却由下游再次截断。5／8 等原有锚点选择口径与父展开后的子证据条数分开，实际展开集合由统一 token 预算控制。

固定 RAG 和 Agent 使用同样的结构化选择规则。旧单来源版本保留原字符预算与旧记录读取，必要时在现有选择版本／预算字段中区分；混合选择包含结构化版本时使用统一的结构化选择流程，旧子证据仍按其真实旧来源读取，不要求用户管理两套预算。

`parent_id`、`source_spans`、章节与内容类型在当前投影中完整保留。最终 `allowed_citation_ids` 只包含实际展示的子证据；历史和下载输出消费同一最终上下文，不建立另外一份审核集合。

### B4. 引用回查与来源显示

继续使用现有四字段 `EvidenceRef` 引用页内子块，不扩成一个覆盖多页的虚构引用。`citations.py` 通过原子块 ID 回查相同版本及存储文本，保留现有引用是否已展示、文本一致及 PDF 页码等职责；不添加第二轮引用审核或新的哈希。

新子块的多个来源范围传递到现有 `sources`、展示记录及下载输出；`app.py` 在既有“来源定位”展开区显示实际页码、各 bbox 及结构内容角色。坐标按 A 保存的坐标系解释，多栏范围逐条显示，不合并为大矩形。B 不新建 PDF 编辑器或可视标注工具。

公式、表格转录保留其区域来源；图像资产仅传递已有位置和关联，本批不新增图像理解调用、OCR 或视觉问答流程。旧来源输出仍可读取。

### B5. 在现有 mapper 中支持多来源

`build_paragraph_mapping` 增加结构化输入分支，与旧单 segment 路径共用现有归一和对齐逻辑，不另建一个 mapper。以实际 `child.text[text_start:text_end]` 读取 span 内容，按版本内子块及 span 的实际顺序重建文本；不能按块 ID 字符串排序而改变阅读顺序。

依据 `block_id`、`source_field` 和可用的源字符范围识别重叠，保留匹配字符到实际子块文本区间、页码、bbox 的回投关系。源字符范围为空时只使用已有区域与子块文本位置，不伪造 PDF 字符偏移。父内容用于运行时阅读，不能在 mapper 中补入子块未保存的文字。

保留 2.6 的连字／标点／引用差异和跨块对齐，以及重复短标题的歧义处理。段落身份可定位与 chunk 全文覆盖分开：chunk 仍要求所有非空白字符对应，部分覆盖继续为未完整映射；不能删除公式、编号或图表字面来提高比例。

只在现有原因／coverage 结果中区分“已关联段落但部分未覆盖”和“尚未关联段落”，并说明已有来源角色。不能仅凭类型就把全部图表判为数据集范围外。48 个子块与 83 个原始段落保留在各自分母中；Answer F1／Evidence F1 算法、参考答案、null 与共同可评集合规则不变。
