## 3. 任务一：回答围绕问题组织

### 3.1 调整现有作答约定

在 [context.py](D:/course/paper-research-assistant/paper_assistant/context.py) 的共享 ANSWER_ORGANIZATION_INSTRUCTION 中整理现有重叠约定，突出以下行为，不继续叠加多份同义警告：

- 根据原问题组织主张，覆盖所问事实、关系和必要解释；不为凑段落数扩写论文的其他部分。
- 作者给出的影响或推测保留其限定语。自己的分析明确标为分析，但其中作为前提的论文机制仍需要原文支持。

这些规则同时作用于 claims 和被请求的 direct_answer，不改变现有结构化答案协议。最终原文照常保存，不在输出后裁剪、删除或替换错误句子。

查询规划继续使用现有入口，不增加题型分类器、答案提纲模型或生成前审核调用。按现有方式更新受影响的提示版本。

## 4. 任务二：按现有章节入口补读阶段定义

### 4.1 目录只提供定位，不生成新知识

在当前页面自主 Agent 的 selected_papers 展示中提供一个简短阅读目录。通过 [storage.py](D:/course/paper-research-assistant/paper_assistant/storage.py:658) 的 get_version_parents，使用已有 section_path、parent_id 和来源页码：

- 按已选论文与版本分别列出原节名，以及该节正文的父块入口；同节多个父块按原阅读顺序保留入口。
- 不加载父块全文作为目录，不生成摘要、阶段标签或新章节树。原节名缺失就保持缺失，不猜测“识别／替换”等语义标签。
- 目录是本次模型输入的普通定位信息，不新增数据库表、持久化清单或一套派生身份。目录本身不能作为 citation_ids。

对已经选中的证据，在模型展示时按论文与原节名区分上下文，同组内容按原阅读顺序呈现；原检索 rank、所选证据集合、子块 ID 和文本保持原值。只展示一份正文，不同时发送平面和分组两份全文。目录和证据展示共同使用现有结构证据预算，保留直接回答问题的关键原文优先。

### 4.2 增加一个本地 read_context 工具

工具只接受已有目录或证据中的 parent_id，从当前已选版本读取该父块真实 child_ids 所指向的子块。模型可先通过现有 search 定位，也可根据目录找到阶段定义入口后直接补读。

| 现有位置 | 必要改造 |
|---|---|
| [agent_actions.py](D:/course/paper-research-assistant/paper_assistant/agent_actions.py) | 在现有原生工具定义旁增加 read_context 的最小参数定义；复用所选版本约束与存储查找，不另建校验框架 |
| [evidence_reading.py](D:/course/paper-research-assistant/paper_assistant/evidence_reading.py) | 抽用已有父块读取与子块展开逻辑，供自动续读和显式补读共同使用；返回真实原文、节名、页码、子块引用 ID 和来源 |
| [agent.py](D:/course/paper-research-assistant/paper_assistant/agent.py) 的自主循环 | 注册并执行 read_context，按既有 tool_call_id 回填，将新读子块纳入累计证据，后续搜索合并不得丢掉已经显式读入的内容 |

工具读取 get_parent／get_version_chunks 已保存的数据，不发 embedding 或重排请求，不把整个父块伪装成新的引用 ID。遇到不可用入口、版本不符或来源范围限制，按现有工具错误／受限结果回填；不转而读取未选论文，也不虚构章节定义。继续保留原来源限制和字符偏移含义。

自动父块续读保持现有用途；新增能力是模型能主动定位并读取另一阶段的定义正文。不是每问固定增加一次工具调用，也不强制重读已经完整可见的内容。

### 4.3 沿用现有边界

保留五步自主决策及最多五次模型发起的取证调用。原 search 额度计数扩展为 search 与 read_context 共用的额度；一次显式阅读也占用一次，不能变成五次搜索再加五次阅读。自动父块续读不额外计为模型工具调用，仍受现有可见证据预算限制。

预算仍为当前 8192 token 结构证据预算，最终答案沿用原预算、发布和修复次数。显式读取的原文不等于全部已经进入上下文，工具观察应区分实际展示内容与未展示内容；只让最终可见的子块进入引用集合。使用既有选择与预算逻辑，不增加预算审核器。

固定 RAG 继续使用原检索入口，仅消费共享作答约定；本地补读工具先用于当前页面自主 Agent。不更换模型，不改变原生工具调用协议，也不新增额外的模型提取或裁判请求。
