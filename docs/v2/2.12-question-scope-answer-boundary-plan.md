## 3. 任务一：首问保留原文，查询规划独立承担检索职责

### 3.1 首问不再请求模型润色作答问题

修改 [conversation.py](D:/course/paper-research-assistant/paper_assistant/conversation.py:76) 的 `prepare_conversation`：

- 没有历史、需要查询规划时，同一次准备调用继续生成 `planned_queries` 和必要的澄清；不再要求模型生成首问的 `standalone_question`。无需澄清时，由程序用用户原始 `query` 填充现有 `standalone_question`。
- 模型可以给搜索词补上所选论文名称、英文术语和检索对象。问题字段不因此增加新指标、新比较维度或新的“为什么”。查询建议继续由 Agent 按实际缺口选择，不变成必须执行的队列。
- 如果首问确实缺少必要对象，保留现有 `clarification_question` 流程。不能为了固定原文而把无法确定对象的问题直接送去回答。
- `plan_queries=False` 且无历史时，沿用已有直接返回原问的路径；不增加准备调用。

首问保留由代码分支完成，不新增一个模型来判断改写是否忠实，也不新增问句字符串比较或拦截机制。现有字段继续使用，不新建一套问题状态或协议框架。

### 3.2 多轮只补全当前所问

有历史时继续使用现有一次准备调用理解指代、结论编号和澄清回复：

- 只补论文、方法、实验对象及必要指代，保持用户当前要求的事实、关系和表达意图。
- 不把“这个区间是多少”改写成“点值、区间与领先情况分别如何”；也不把“解释这一条”自动扩成完整论文综述。
- 有多个合理对象时继续澄清；历史答案仍只帮助定位，不能当作已核实的论文事实。
- 保留用户原问与补全后问题的现有记录。最终回答遵循当前原问的意图与限制，历史补全只用于消除指代歧义。

首问的来源要求从原问确定；多轮的来源要求从保留原限制的补全问题确定。继续复用已有来源限制处理，子查询不能扩大论文、版本、摘要等范围。

[d9_runtime.py](D:/course/paper-research-assistant/paper_assistant/d9_runtime.py:172) 已将准备结果接到实际核心调用。本批确认首问原文、多轮补全和查询建议沿现有链路传递；只在实际字段投影或调用存在不一致时修改该处，不另建运行入口。

## 4. 任务二：缺少论文事实时，允许用所问缺口完成回答

整理 [agent_prompt.py](D:/course/paper-research-assistant/paper_assistant/agent_prompt.py:25) 与 [context.py](D:/course/paper-research-assistant/paper_assistant/context.py:89) 中“必须给有用分析”“不能只有不足说明”等约定，采用以下行为边界：

| 用户所问 | 回答方式 |
|---|---|
| 所问论文事实已取得 | 完整回答该事实及理解它所必需的条件、单位和解释 |
| 所问论文事实未取得 | 说明当前证据缺少什么、因此哪些内容无法确定；仅补充理解该缺口所必需的区别，不自动转向介绍其他论文结论 |
| 用户明确要求机制、原因、比较或推论 | 按要求展开；论文事实前提仍需对应原文，推论与论文结论分开 |
| 用户询问通用概念或明确要求方法建议 | 保留通用知识与分析能力，避免把本批收紧误变为一律拒答 |

例如，问区间上下界而证据只有准确率点值时，缺口说明本身就是有效回答内容。可以解释“点估计不能替代区间”，不需要附加各模型排名或逐类别优劣。论文没有提供的上下界不能自行估算。

不设置固定字数、固定 claims 数量或一律禁止补充的规则。问局限及其影响时仍需解释影响；问替换机制时仍需解释实际机制。目标是完成所问，不以缩短答案替代回答充分性。

### 4.1 保持现有答案结构

继续使用 `AnswerAction`／`AnswerDraft`。所问事实无法从当前证据确定时：

- 被请求的 `direct_answer` 沿用现有规则返回 `Unanswerable`，信息缺口在 claims 中说明。
- 允许用一条清楚的缺口说明构成非空 claims，不为满足结构要求制造其他事实或分析。未取得资料的说明按现有 analysis 方式表达，不能附无关引用伪装成原文证明。
- 仍按当前协议发布 `status="answered"`；这表示完成了本轮回答，不表示所问论文事实必然可得。不切换业务状态、答案 Schema 或前端状态展示。
- 短引句继续用于已读原文和分析前提的追溯。没有对应原句的缺口说明不编造引句，不扩大 citation_ids 权限。

统一普通回答、步骤上限收尾及原有格式／引用修复提示中的同类表述，避免正常回答允许说明缺口、修复阶段却又要求扩写分析。保持原修复次数与工具边界，更新实际受影响的提示版本。

### 4.2 数字比较沿用已有范围要求

保留当前数据集划分、指标、单位与比较对象的约定。确需回答数字比较时，以具体表格列和数值限定结论；原文概括句存在歧义时，不直接扩大为所有类别或所有条件。

本批不新增表格理解模块、指标分类器或逐句判定器，不将“再次增加 All 规则”列为独立任务。语义效果仍由实际输出与原文对照判断。
