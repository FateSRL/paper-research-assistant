QASPER 统一要求模型根据问题和可见材料给出“最短充分答案”：是非问可为 Yes／No；实体、数字、列表保留全部所问项；解释型问题给必要的完整答案，不设统一字数上限。材料不能确定答案时，允许模型自行给出 `Unanswerable` 并在 claims 中解释缺口；不依据 gold 的 yes_no／unanswerable／答案类型选择输出。现有不足证据状态的转换继续兼容。

直接答案与解释由原来的同一次 answer 生成。不能新增答案类型分类器、答案抽取模型、翻译或裁判请求，也不能在看过参考答案后裁剪、改写或挑选预测。原问题加统一指令即可，不能把参考证据、答案类型或结论位置塞进问题。

原始 `user_question` 会经 conversation_context 进入最终生成，即使 standalone_question 被改写仍保留原表达。系统协议要明确支持按该表达填写可选字段，不依赖用户后缀去覆盖原严格 JSON 协议；无需新建全局评测模式或额外传参框架。

### 2.2 贯通实际发布与历史兼容

固定 RAG 的 AnswerDraft 解析和 Agent 的 AnswerAction.answer 使用同一 schema。沿实际 `model_dump → 引用验证 → 发布 answer` 路径保留 direct_answer，JSON 历史与逐题预测保存该字段。现有字典传播已能保留普通字段，只有发现具体丢失位置时才修改该消费者；不顺带重构 UI 或全部导出格式。正常页面省略字段时保持原解释展示。

现有一次格式修复、引用修复和 Agent 动作修复继续使用同一答案协议，修复后保留直接答案和 claims，不增加修复次数。direct_answer 应与解释保持一致，仍由同一次生成负责，不添加第二轮语义审核。

在既有批次 input／summary 中记录普通字段 `evaluation_protocol="qasper-direct-answer-abstract-v1"`，由 run、离线 score 及汇总一致消费。新协议的 answered 输出缺少有效 direct_answer 时，按预测协议缺失记录并沿既有失败记分，不能悄悄拼接 claims 代替。历史无该协议的批次仍按原长答案方式读取，原 C1 分数不改写，也不拿旧长答案按新协议事后重新提取。

模式选择只贯通现有入口和汇总，不增加调度框架。`summarize_qasper` 按所选 modes 计算已尝试、完整尝试及共同可评集合：Agent 单模式的共同集合即其自身可评题目，未选 fixed_rag 不生成质量分数，也不计失败或未完成。沿用已有实际报告账本，不重写费用统计；最终双模式对照仍可显式选择两模式。

## 3. 将确定的摘要作为真实预测证据计分

### 3.1 摘要单列，不改变正文段落身份

`build_paragraph_mapping` 增加可选 abstract 输入，由现有导入／映射调用方传入样本已保存的 `paper["abstract"]`。它只用于离线对应与评分，不替换实际 PDF 检索语料，也不进入模型输入。

摘要记录独立于正文 paragraphs，例如 `abstract_evidence` 下的 `abstract:p0`：保存官方原始字符串、状态、真实位置和 chunk_ids。正文原有 `sN:pM`、83 段分母与正文覆盖统计不变；摘要是否定位单独说明。本次首篇版本仍是旧 `r_dba11bd81925f9fd` 与新 `r_14605272e1dd1378`，不改变 PDF、来源存储、分块或索引。

摘要定位复用现有完整普通词有序对应与来源回投。官方摘要有 `\babi-10k`、PDF 写作 `bAbI-10k`，可仅在摘要匹配视图处理大小写和词前 TeX 反斜线等已确认的表示差异，保留原文和真实偏移。规则不能硬编码这篇论文或词项，不能扩展成数学等价平台；普通词缺失、重复位置无法区分等情况仍未确定，不能仅凭 Abstract 标签、首尾相似或比例阈值确认整块。

### 3.2 按全部真实引用评分

chunk 的可评分归属依据正文与摘要已确定的真实范围并集判断。摘要与已知正文混合时保留全部对应；混入未知正文、独立公式或其他未归属内容时仍保留缺口，不能因含有摘要就整块放行。原逐字符覆盖仍保留其诊断含义；新输入注明正文加摘要的证据范围，不能拿它和 B 后续纯正文归属率冒充同一指标提升。

`map_evidence` 同时解析正文与摘要身份，预测证据使用官方原始字符串；摘要不属于该题 gold 时，原 `paragraph_f1_score` 自然将其计为额外证据并扣 precision。原字符串相同的证据按既有集合规则去重，不根据相似度将摘要冒充 gold 正文。不删除摘要引用，不根据 gold 决定该引用是否进入预测，公式、参考答案及多参考取最大值规则不变。
