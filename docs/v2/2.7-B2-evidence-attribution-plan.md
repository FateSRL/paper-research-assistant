## 1. 本批要解决什么

B 首轮已经接通两模式父上下文、8192 token 预算、实际子引用及多来源映射。首篇 `1603.01417v1` 的结构版本 `r_6d19bd2ad7b501e3` 有 33 父／48 子，一次映射为 70／83 段、9／48 子块全文覆盖，另 22 个部分覆盖、17 个未关联。这些是输入对应情况，还不是回答准确率。

继续查看已保存的来源和映射后，已确认以下具体原因：

| 原因 | 现有证据 | 本批处理 |
|---|---|---|
| 段落身份与逐字符覆盖混为一个评分门槛 | 22 个部分覆盖中，10 个非空白字符覆盖已达 95%；如 `p1_c2` 为 99.13%，遗漏主要是 `(Xu et al., 2015)` 的归属 | 保留字面覆盖诊断，另行确定段落归属；不以 95% 阈值直接放行 |

| 标题在来源与章节元数据中，未进入 child.text | Input Fusion Layer、Episode Memory Updates、Text QA Results、Results and Analysis 四个标题的来源均存在 | mapper 使用实际 heading 来源定位，不把整个章节的子块都算成标题证据 |
| 两个参考文献块误入正文 | References 下 p8:2–p8:12 被解析为普通 text，形成第 9 页 `c2/c3`；同节的 `c1` 是真实图注 | 修正结构适配中的文本角色，复用已有解析生成实际新版本 |

旧版 75／83 到新版 70／83 的差额，正是上述四个标题及训练正文；原有的六段公式、一个重复短标题和 `s1:p8` 正文差异仍存在。不能把整批问题都归为 PDF 没读出来。

## 2. 实施顺序与范围

### 2.1 修正参考文献的真实入库分类

在 `mineru_parser.structure_units` 现有结构角色转换处处理：章节标题规范化后完整等于 References、Bibliography 或参考文献时，将其下普通 text／list 参考文献条目归为已有 `reference` 角色，让现有跳过规则生效。保留独立识别的 image、table、caption 等角色，不按页号或整个章节删除；不硬编码本篇 ID、作者名或块 ID。

这项修改会改变真实分块集合，应更新现有 `adapter_revision`，通过 `structured_ingest.py` 的解析复用路径读取已保存 MinerU 输出和资产，生成实际的新 `parse_revision` 并正常入库。父子数量以实际输出为准，不预写为 46 子块，也不在旧 ready 版本上直接删记录。沿用现有向量缓存及索引流程；如果新版本正常索引需要 embedding 请求，属于该次真实入库，不把它放进离线测试。

不重跑 MinerU、不重新下载模型。分类修复在来源端完成，本批不再叠加另一套检索候选过滤。

### 2.2 在既有 mapper 中恢复跨页接缝与标题定位

扩展 `build_paragraph_mapping`，允许调用者提供同一版本已有 parents／sources；旧调用仍可只传 full_text、chunks。实际数据从已打开 store 或已有版本文件读取，不新增跨会话缓存、映射服务或通用命令行。

跨页接缝只在父子关系、来源范围及已保存父文本能共同证明时使用零间隔连接，保留到两个真实 child.text 区间的回投。只改变匹配用的文本视图，不改写引用正文、不把父文本中子块未保存的字符补进子证据，也不对任意相邻块猜测拼词。

标题使用 sources 中真实 heading 的文本、页码、bbox、章节顺序定位。只有标题和相邻正文关系能唯一确定时才确认；重复的 Attention Mechanism 等仍保留歧义。标题不在 child.text 中时，记录其实际 heading 来源，不能伪造子块字符位置。标题的原始段落定位与可引用子块投影分开：未作为该子块实际内容／已展示元数据的标题，不凭同一 section_path 就向该子块预测集添加标题段落。

### 2.3 将字面覆盖与证据段落归属分开

继续保留现有 chunk `status`、`reason`、逐字符范围和 `chunk_mapping_rate`，用于说明实际文字覆盖及历史比较。在同一 mapping 记录里增加命名明确的段落归属结果、依据范围及对应计数；不把新的归属比例写回旧的全文覆盖指标。

归属规则限于已经唯一定位的 QASPER 段落和真实来源范围：已知的引文／BIBREF 表达差异、行内 LaTeX 格式、标点与空白变化，可在确定段落边界内归入同一段。不能仅因覆盖超过 95%、属于同一父内容或相邻章节，就把整块归给某段。

一个子块包含多个原始段落时，保留全部已确定段落；仍有无法归属的普通正文、第二个未知段落或独立公式／表格证据时，该子块的归属仍为未完成。单独的公式或图表不能只靠邻近正文被强行归入。行内公式的来源归属成立，也不表示已验证其数学转录正确。

`map_evidence` 有新归属结果时据此判断证据映射资格；读取旧 mapping 时沿用原判断。Answer F1／Evidence F1 的计算公式、全部参考答案、null 语义和共同可评集合规则不变。预测到已定位但与答案无关的段落，仍进入预测证据并正常计入假阳性，不能挑出有利段落后再评分。

这一步修正的是 PDF 到官方段落的投影。不得用官方 full_text 替换实际 PDF 检索语料，不读参考答案来选择预测证据，不用相似度或模型裁判宣告对应。`s1:p8` 的 QASPER 尾部异常与 PDF `question q.` 差异继续保留，不加入删字符或论文特例。
