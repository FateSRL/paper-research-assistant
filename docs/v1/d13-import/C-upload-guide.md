## 使用方法

使用 README 中原启动命令打开 `http://127.0.0.1:8501`。侧栏展开“添加论文”，上传可提取正文的 PDF，按需填写标题和链接，点击“开始入库”。标题留空使用文件名；纯扫描 PDF 暂不支持。

看到“已入库”后，在“本次阅读的论文”中选择它，使用现有固定 RAG／Agent 提问和连续追问，点击有引用的句子查看该轮原文。失败时点击“重试入库”；如要换 PDF 或元数据，使用“开始入库”提交新的材料。
