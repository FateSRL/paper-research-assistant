# D12 执行计划：检索不足仍回答或解析

制定与完成日期：2026-10-08（Asia/Shanghai）。**D12 A–C 已完成实现，下一步 D13 混合检索。** 本阶段承接 D11 的论文信息、缺口化补查与正文获取。它调整回答方式，不新增检索轮数或独立模型阶段。4 个相关现有离线方法通过，未新测真实模型效果。

## 1. 目标

正常问答中，检索为空、没有相关论文证据，或一次补查后仍不能支撑完整答案时，继续给出与问题有关的回答或解析。能由原文支持的内容保留真实引用，其余内容明确属于模型知识或分析；涉及所选论文的未知具体事实，不凭模型记忆冒充已核实事实。

例如询问与论文无关的概念，可以直接解释概念并标明模型知识；询问论文未展示的实验结果，可以解释该问题需要什么信息、怎样理解相关指标，而不编造这篇论文的具体数值。不能只把“检索不足”作为正常分支的最终答案。

## 3. 范围与必要验证

- 复用现有结构化生成、Agent 决策与修复调用、一次补查、来源定位和运行记录；不单独加入意图分类、HyDE、RCS 或额外回答模型阶段。
- 保留现有来源范围对论文原文引用的约束。模型知识不计作论文原文支持，不把原文之外的解释附到任意论文引用上。
- 技术故障、无可用聊天预算、超时或模型输出持续不合规仍按实际失败状态报告，不能伪造模型回答。D12 的目标是正常证据不足时提供有用内容。
- 普通小改动只选择 1–3 个覆盖实际行为变化的相关现有方法；只有失败或具体跨模块影响才扩大。本轮涉及固定 RAG、Agent、来源范围和页面/导出四处实际调用链，选择 4 个现有方法覆盖，不按模块或目录运行。文档不跑测试，已通过且代码未变的结果复用。
- 离线验证使用模拟响应和临时资源，不发起真实模型或 embedding 请求；不重跑整批 D10、D14 验收，不增加哈希、审计、快照或独立验证报告。
