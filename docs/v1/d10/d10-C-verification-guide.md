## 4. 练习与参考答案

### 题 1：C 计划提到选择 1–3 个现有方法，为什么这次没有运行测试？

**参考答案：**方法数量不是必须凑齐的指标，应根据实际改动选择。本次只改系统提示文本和版本常量，消息结构、动作解析及补查执行逻辑没有改。已有修改文件语法解析通过且代码未继续变化，可以直接复用。重复结构测试不能判断新提示对真实模型的效果，因此不作为本次必要验证；D/E 承担实际输出与语义评价。

### 题 2：提示会改变模型行为，为什么“语法通过”仍不能写成“机制回答修复成功”？

**参考答案：**语法通过只说明 Python 能解析文件，不能说明模型遵循了新增要求。D2-002 需要观察模型是否认识到缺机制证据、是否选择有用的补查、最终展示是否包含所缺依据，以及答案是否完整覆盖原问题。D 保存实际轨迹和输出，E 根据实际引用和原问题判断结果。只有这些证据出现后，才能说明新版本在对应开发题上的表现。

### 题 3：只改版本常量，不改 `AGENT_SYSTEM_PROMPT`，能让模型更会补查吗？

**参考答案：**不能。版本常量是标识文字，由 [build_agent_messages()](/D:/course/paper-research-assistant/paper_assistant/agent_prompt.py:102) 写进消息字典，由 [answer_question_agent()](/D:/course/paper-research-assistant/paper_assistant/agent.py:73) 写进结果字典；它帮助区分使用的提示版本。真正提出新决策要求的是系统提示文本。这次同时修改了文本和标签，但是否有效仍需实际输出。
