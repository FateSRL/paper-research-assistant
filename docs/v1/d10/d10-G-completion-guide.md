## 6. 练习与参考答案

### 题 1：怎样用一段话讲清 D10 的故事链？

**参考答案：**D9 的 D2-002 初轮缺文档使用机制，Agent 提前回答相关事实。D10 A/B 在现有系统提示中要求覆盖原问题，缺关键依据且允许有用补查时补查。C 复用已有修改文件语法结果；D 新建同一版本完整开发批次，E 根据实际展示和引用确认 D2-002 Agent 补查后 4 条 Claim 有据且机制完整。F 固定版本并公开保留其他已知问题，G 总结交接给 D11。每步分别有记录，不能只说“改了提示，所以答对了”。

### 题 2：新增 3 段 chunk 是不是补查成功？

**参考答案：**只能说明补查新增了展示，不能说明所求缺口已被填补。D5-005 的新增片段仍属于 RAG 预处理、图标签或参考文献，没有 Reflexion / HotpotQA 停止规则，所以没有答案增益；最终不足仍合理。D2-002 和 D2-003 的新证据支持原问题的必要部分并完成回答，才有本批次的答案增益证据。

### 题 3：为什么不把 Agent 的 17 个 `answered` 写成 17/17 准确率？

**参考答案：**`answered` 是程序发布状态，必要内容覆盖是回应问题的判断，严格完整支持还要求引用支持全部内容和限定。Agent 严格正题为 15/17，D3-004 实验归属与 D6-003 生成者表述仍有缺口；负题合理拒答另记 3/3。39 与 50 条 Claim 的支持统计也不能替代题目完成率。所有数字为 AI 开发观察，人审 pending，不能报告人工准确率或验收成绩。

### 题 4：`completed_with_known_issues` 与冻结版本是什么意思？

**参考答案：**它表示 D10 A–G 的工作和记录范围已完成，已知问题已明确保留，并采用同一完整开发批次、两种提示版本和现有配置进入后续阶段，不表示所有题都满分或验收已通过。冻结是采用该版本的约定，不是需要再建哈希、锁或快照。后续如需改变源码、提示或配置，应记录新版本及对应新批次。

### 题 5：可以将 D10 的不足换成 D9 的成功答案，或者继承旧答案的人审确认吗？

**参考答案：**不可以。不同批次可能使用不同版本、展示和策略，拼接会让成绩不再属于同一完整版本。每批保留实际首次、不足和失败，新批次复测也保留各自记录。用户确认旧答案只覆盖其实际确认范围，不能自动确认 D10 新答案；已经确认的历史范围保留，仍待人审的旧批部分、D10 新答案和恢复稿继续 pending。

### 题 6：D10 已完成，D11 可以直接把 dev 命令改名执行验收吗？

**参考答案：**不能。当前 dev runner 没有验收 split，D11 先实现专用入口，隔离题面/选定版本与事后标注，分开准备和真实执行，再针对新增路径选择必要的 1–3 个相关现有方法。通过后用新验收批次保留首次、失败和用量，沿用已冻语料、profile 和 budget。本次 G 只交接这些待办，没有实现或运行它们，也没有读取验收题面。
