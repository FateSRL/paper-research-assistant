规则面向同类问题，不读取题号、标准答案或目标 chunk 来决定补查，不把 Sequence / Token 的答案直接写进提示词，也不新增模型输出字段或程序完整性判定层。固定 RAG 继续一轮策略；D2-002 的固定模式拒答与其展示相符，不为追分强制改成回答。只有实际证据指出固定生成也偏离原问题时，才调整它使用的现有提示词。
