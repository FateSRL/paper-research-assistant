## 1. 本阶段目的

2.17 已证明固定原文可以通过成功准备的消息历史传到最终生成，也观察到最终补足准备遗漏；该题核心答案此前已覆盖，新机制增加了输入成本，并出现有据但不必要的背景扩写。本阶段保留该实现，先用十题完整 Agent 流程扩大观察，再决定是否需要局部修正。

本批要观察的是检索、阅读、准备、最终表达与引用的完整衔接，以及原问覆盖、事实忠实性和实际成本。它是已有开发案例的当前版本观察，不是新的留出验收，不用十题通过率声称一般准确率，不比较固定 RAG 或提前编译知识路径。

## 2. 运行条件与范围

- 实际调用页面对应入口 `d9_runtime.run_question(..., mode="agent", library_mode=True)`，保留前置理解与规划、模型自主选择工具、临时事实准备、原文历史重放、最终生成与现有引用发布。

## 5. 评价口径

以本轮完整回答及其实际获得的原文判断，每题在现有结果中记录：

1. 核心所问是否回答完整，必要并列项、关系、适用条件和模态是否保留；正确但不必要的背景另记聚焦问题，不因篇幅长直接判事实错误。
2. 主体／方法阶段／论文归属、公式、数值及结论强度是否受到原文支持；引用可定位与语义支持分开判断。
3. 缺少事实时是否明确当前证据边界，是否无据推断“不存在”；追问是否正确继承本轮对象和要求，旧回答没有变成新证据。
4. 实际经历哪些搜索／阅读、是否触发不足后补证、哪些材料最终可见；未自然出现的分支记为未覆盖，不用强制动作凑覆盖率。
5. 前置理解、取证、准备、最终及修复／重试的真实请求、token 和耗时；2.17 固定证据耗时不与本批完整 Agent 直接相减后声称提速或退化。

内容可记为通过、部分通过或失败，运行失败单独记录。说明评价为 AI 辅助原文对照，不冒充独立人工准确率；准备数量、引用数量、发布成功或词面 F1 不单独决定内容结论。缓存差异及输入长度会影响成本，token 不直接按同一比例换算费用。

## 6. 错误处理与停止条件

- 逐题一次，保存全部实际输出；不为获得更好答案重新生成，不边跑边改提示后把不同版本混成同一批。

- 出现索引不可用、模型配置错误、原文历史缺失等影响后续执行的运行故障时暂停排障，记录已发生调用；未完成题保持未执行，不虚报零成本或自动重开整个批次。
- 完成上表十题及已有结果的简要评价后结束；若中途故障或第 9／10 题依赖无法满足，则保留实际完成数／10 和原因。任务完成不要求调到 10/10 内容通过。

### 9.3 最小改动

主要修改 [agent_prompt.py](../../paper_assistant/agent_prompt.py)中实际发送的准备规则和最终规则，整理现有重叠约定，不再堆叠另一套同义警告或重复动作协议。

**A. 最终术语与技术含义保真**

- 原文已有技术名称时保留其含义、阶段和适用条件；原文只描述一种表示时，优先使用该描述，不凭熟悉程度为它另加更具体的技术类别。
- 准备事实中的正确定义在翻译、比较、缩写及 analysis 中都应保持；允许忠实改写，但不能把表示性质、约束或机制改变成另一类。
- 事实段已直接完成所问时，不为形成“因此”总结重复列举一遍事实并重新命名。用户要求解释或推论时正常回答，论文前提继续以当前原文为准。
- 规则使用通用职责，不在生产提示中加入本题食材、one-hot、多热向量或预期答案的专用映射；不建立术语黑名单、正则替换或事后答案裁剪。

**B. 准备阶段绑定完整跨块来源**

- 提取事实前结合当前已提供的原文确定完整主体、关系和必要条件。句子跨块或跨页时，不能只从续文摘一段，就把从前块读到的主体无来源地补进 claim。
- 一项事实实际由 A、B 两块共同支持时，在该事实的既有 `citation_ids` 中列出 A、B；需要引句时分别使用各自 chunk 中连续的原句片段，不拼接成一条假原句，不把 A 的文字挂到 B。
- 一块已完整支持的事实仍只引用必要块。块相邻、同父块或同页不自动构成支持，不能为避免遗漏把整段全部 ID 都挂上去。

**C. 最终合并保留支持关系**

- 最终每条 claim 的引用应支持该条完整内容；将多项事实合成比较、列表或解释时，保留合并后实际需要的各个来源。
- 准备的来源集合只是参考，不是已审核结论。原文显示准备漏引时，最终可以使用 2.17 已开放的真实可见块补齐；原文仍不足时，只表达有依据的部分和具体缺口。
- 另一条 claim 引用过某块不能替代当前 claim 的来源。需要拆句时按真实支持关系拆，不以拆句掩盖跨页半句仍依赖两块。

保持 `facts / answerable / missing_information`、Claim／EvidenceQuote、AnswerAction、五步与五次取证、8192 token、模型和共享修复预算。更新实际受影响的准备／最终提示版本；若普通固定证据提示复用同一规则，保持对应规则一致，不新建配置开关。`agent.py`、原文窗口、schema、存储、解析、索引及现有来源／引用检查本批无需重做。
